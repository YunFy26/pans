# 并发同步机制
```text
并发同步机制
├── 互斥同步
│   ├── 互斥量                            // 也常称为互斥锁
│   │   ├── mutex
│   │   └── shared_mutex
│   └── RAII 锁管理器
│       ├── lock_guard                   // 功能简单，构造时加锁，析构时解锁
│       ├── unique_lock                  // 支持延迟加锁、提前解锁、转移所有权等操作
│       └── shared_lock
│
└── 原子同步
    ├── atomic
    └── cas

锁管理器的核心作用是利用 RAII 自动管理互斥量的加锁和解锁，避免手动调用 lock() 和 unlock()
```


## 互斥量
### mutex
`mutex`同一时刻只允许一个线程进入临界区

```cpp
#include <mutex>

std::mutex mtx;
int value = 0;

void increment()
{
    std::lock_guard<std::mutex> lock(mtx);
    ++value;
}
```


### shared_mutex
`shared_mutex`读写锁，支持两种访问方式：
- 共享锁：允许多个读取线程同时持有
- 独占锁：只允许一个写入线程持有，并排斥所有读取线程

```cpp
#include <mutex>
#include <shared_mutex>
#include <string>

std::shared_mutex rw_mutex;
std::string data;

std::string read_data()
{
    std::shared_lock<std::shared_mutex> lock(rw_mutex);
    return data;
}

void write_data(std::string new_data)
{
    std::unique_lock<std::shared_mutex> lock(rw_mutex);
    data = std::move(new_data);
}
```

## 原子同步
### atomic
`std::atomic<T>`用于对单个对象执行原子操作
```cpp
#include <atomic>

std::atomic<int> value{0};

value.store(10);              // 原子写入
int x = value.load();         // 原子读取
int old = value.fetch_add(2); // 加 2，并返回旧值
value.fetch_sub(1);           // 减 1
value.exchange(20);           // 写入 20，并返回旧值
```


### CAS
比较并交换
- 如果当前值等于期望值：
    将当前值修改为新值，并返回成功
- 否则：
    将当前值写入期望值，并返回失败

```cpp
#include <atomic>

std::atomic<int> value{10};

int expected = 10;
bool success = value.compare_exchange_strong(expected, 20);
```

template <typename Benchmark>
double RUNS(Benchmark&& benchmark)
{
    long double total_nanoseconds = 0.0L;
    for(int run = 0; run < RUNS; ++run)
    {
        total_nanoseconds += static_cast<long double>(benchmark().count());
    }
    return static_cast<long_double>(total_nanoseconds / RUNS);
}

template <typename Operation>
std::chrono::nanoseconds BenchmarkThreads(std::size_t thread_count, Operation&& operation)
{
    std::latch<std::ptrdiff_t> ready(static_cast<std::ptrdiff_t>(thread_count));
    std::latch start_gate(1);
    std::latch finished(static_cast<std::ptrdiff_t>(thread_count));
    std::vector<std::thread> threads;
    threads.reserve(thread_count);
    for (std::size_t thread_index = 0; thread_index < thread_count; thread_index++)
    {
        threads.emplace_back([&, thread_index](){
            ready.count_down();
            start_gate.wait();
            operation(thread_index, OperationsForThread(thread_index, thread_count));
            finished.count_down();
        });
    }

    ready.wait();
    start_gate.count_down();
    finished.wait();
    for(std::thread thread : threads)
    {
        thread.join();
    }
}

std::chrono::nanoseconds BenchmarkMutex(std::size_t thread_count)
{
    g_Counter = 0;
    const auto elapsed = BenchmarkThreads(thread_count, [](std::size_t, std::uint64_t operations){
        for(uint64_t index = 0; index < operations; ++index){
            std::lock_guard<std::mutex> lock(g_mutex);
            ++g_Counter;
        }
    });
    return elapsed;
}

std::chrono::nanoseconds BenchmarkSharedMutex(std::size_t thread_count)
{
    g_Counter = 0;
    const auto elapsed = BenchmarkThreads(thread_count, [](std::size_t, std::uint64_t operations){
        for(uint64_t index = 0; index < operations; ++index){
            std::unique_lock<std::mutex> lock(g_sharedMutex);
            ++g_Counter;
        }
    });
    return elapsed;
}

std::chrono::nanoseconds BenchmarkAtomic(std::size_t thread_count)
{
    g_atomicCounter.store(0, std::memory_order_relaxed);
    const auto elapsed = BenchmarkThreads(thread_count, [](std::size_t, std::uint64_t operations){
        for(uint64_t index = 0; index < operations; ++index){
            g_atomicCounter.fetch_add(1, std::memory_order_relaxed);
        }
    });
    return elapsed;
}
